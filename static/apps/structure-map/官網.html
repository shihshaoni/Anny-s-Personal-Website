為何要先付款？

這是定制型專業服務，需投入時間與研究。為確保排程與品質，我們採「先付款再開始」。若未依期限交付，提供退款保障。

你用哪些工具？會不會需要我付額外訂閱？

交付完全以免費工具為主：Google Docs / Notion / Canva / Meet。若你沒有帳號，可用免費版註冊；不會要求付任何第三方訂閱費。

如何保護內容與著作權？

我們以工作合約（Email 條款）確認：你保有完整著作權；我們僅在交付過程中閱讀與提出建議，不會公開或再利用你的文本。

Premium 能幫我「代寫」嗎？

不提供代筆；我們提供結構與語言層面的專業建議與示例改寫片段，保留你的作者聲音。
